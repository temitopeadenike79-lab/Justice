# Justice# 🌍 African News Pulse: Key Updates

A clean, responsive HTML/CSS news summary dashboard focusing on critical events across West, Central, Southern, and East Africa. 

![Project Preview](link-to-your-screenshot.png) ## 📋 Overview
This project provides a curated, high-level summary of African news. The focus is on scannability and visual clarity, using a color-coded interface to help readers quickly digest information regarding security, diplomacy, environment, and social issues.

## 🚀 Features
* **Regional Categorization:** Organized by West & Central, Southern, and East Africa.
* **Responsive Design:** Optimized for both desktop and mobile viewing.
* **Visual Hierarchy:** Uses a "Light Sky Blue" palette for readability and custom card-based lists for news items.
* **Lightweight:** Pure HTML/CSS with no external dependencies or heavy frameworks.

## 🛠️ Technical Details
The layout is built using semantic HTML5 and custom CSS styling:
* **Background:** `#87CEEB` (Sky Blue)
* **Typography:** Sans-serif (Arial)
* **Architecture:** Flexbox-ready list structures for news cards.
